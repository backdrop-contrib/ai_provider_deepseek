# AI Provider DeepSeek

Use DeepSeek models for writing, chat, and reasoning in Backdrop. Compatible models can also call tools supplied by an AI feature.

## Installation

Install and enable this module with AI and Key. [Backdrop module installation guide](https://backdropcms.org/user-guide/modules)

Store your service credentials using the Key module. Choose the provider in **Configuration → AI → Settings → Providers**. [Setup and troubleshooting](https://github.com/backdrop-contrib/ai_provider_deepseek/wiki)
